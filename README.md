# Golden Hour

Beyond Ultra graphics for WoW Forever. Hidden view distance, shadow, lighting, water and texture settings, in a Bliz-style window and in Options > AddOns.

- Sliders for over 50 hidden graphics settings, with Bliz's default and the Beyond Ultra value marked on each
- Beyond Ultra preset, from the WoW Forever settings guide, with its crash caps (water detail 2, reflections 3, global illumination 4)
- Midrange and Lite presets for less powerful PCs
- Blizzard Defaults, and Before Golden Hour (everything as it was the first time the addon loaded)
- Undo for the last 30 changes
- Named profiles, with share and import (imports are kept inside the crash caps)
- Type a number into any setting
- Put your settings back when Bliz's Graphics Quality slider moves
- Switch presets or profiles by place: dungeons, raids, battlegrounds, cities and inns
- FPS readout on the window
- Loot sparkle on quest items, kept on when the graphics quality slider moves
- Optional: change the raid and battleground copies too

`/gh` or `/goldenhour` opens the window. `/gh options` opens it in Options > AddOns.
